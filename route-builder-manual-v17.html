1. Route information

2. Start a route

NEW ROUTE MODE — editing is not attached to an existing database route.
Select any existing route to load its current geometry. Newly published routes appear in this list after refresh. Starting a new route creates an empty geometry. This editor contains no OSRM routing at all. Points are connected only in the exact order you place them.

3. Drawing

Click the map to place vertices. Every click is a manual vertex. The editor never asks a routing engine to connect them. Double-click the map or press Enter to finish drawing. After drawing, vertex editing remains active automatically. Use the mode buttons once and keep working until you choose another mode.

4. Edit geometry

Editing modes are persistent. In Edit Vertices mode, click a vertex, Shift-click additional vertices for multi-select, drag points, and press Delete or Backspace to remove the selection.
Draw Segment mode: click one existing vertex, then click a second existing vertex. Then click map points to draw the new segment between them. The new segment replaces/repairs only that connection; nothing else is rerouted automatically.

Help

Important: this version deliberately has no OSRM. It will never automatically create, reroute, or replace any part of your route.

Manual workflow:
1. Click New Blank Manual Route.
2. Click Start Drawing.
3. Click each point on the map in the exact order the bus travels.
4. Finish drawing.
5. Use Edit Vertices to drag points.
6. Use Select Road Segment to select a section directly by clicking the line itself.
7. Double-click a selected segment to deselect it.
8. Use Edit Vertices to click a vertex, then press Delete or Backspace to remove it. Shift-click selects multiple vertices.
9. Deleting a vertex removes that vertex and its adjacent route links; the remaining geometry is redrawn from the remaining vertices.
10. In Edit Vertices, Shift-click as many vertices as you need; the selection stays active until you change it or clear it.
11. Add Vertex and Edit Vertices are persistent modes — you do not need to press the button again for every point.
12. Load an existing route, edit it, then use Save Changes to Existing Route. This updates the same database row and never creates a duplicate. Delete Existing Route permanently deletes the selected route from Supabase.
13. Save a draft, then validate and publish when creating a new route.

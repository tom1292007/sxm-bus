Simple route editor

1. Build Whole Route with OSRM
Use this only to generate the initial route.

2. Erase Section
Click the route where the unwanted section starts, then click where it ends. The selected section turns red.

3. Draw Replacement
Click directly on the correct road. Points are snapped to the nearest drivable road using OSRM's nearest-road service.

4. Apply Replacement
The unwanted section is removed and the replacement is inserted. The rest of the route stays untouched.

5. Save Draft
Saves your current work in this browser without changing Supabase.

6. Publish
Writes the current route to Supabase so the live map uses it.

For Union Road: erase the wrong OSRM section, click several points down Union Road, apply the replacement, inspect it, then publish.
